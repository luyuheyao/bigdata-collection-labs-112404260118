## 三、如果要重新跑一遍

课程环境（JupyterLab + MySQL 8.4.11）已在运行：

1. 打开 JupyterLab，把 `lab02` 文件夹放到工作区（或打开 `anjuke.ipynb`）。
2. 直接 Run All：会自动重新采集、重新生成 CSV，并在入库单元里自动跳过已存在的 8 字段组合
   （所以重跑时「本次待插入 0」，条数仍为 498）。
3. 若想从头验证「0 → 498」，先在 MySQL 终端执行 `TRUNCATE TABLE houseinfo;` 再 Run All。

数据库连接参数（课程文档给定）：`host=mysql`、`port=3306`、`database=smartpark_lab`、`user=student`。
课程教学密码只写在 Notebook 的 `DB_CONFIG` 里（与实验手册一致），不要把 `.env` 或个人密码上传到仓库。
